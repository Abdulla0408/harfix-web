Файлларни ўгириш: Word, Excel, PowerPoint

Файлни танланг ёки шу ерга ташланг — ўгирилган нусхасини юклаб оласиз. Асл файл ўзгармайди.

    Нималар сақланади

    • Шрифт, ўлчам, ранг, қалин/қия ёзув, жадваллар, расмлар, формулалар — ҳаммаси жойида қолади. Фақат матн ўзгаради.
    • Word: асосий матн, юқори ва пастки колонтитуллар, изоҳлар. Excel: катаклардаги матн. PowerPoint: слайдлар ва изоҳлар.
    • Битта сўз бир неча форматга бўлиниб кетган бўлса ҳам (s|h) тўғри ўгирилади.

    PDF, сканер, эски .doc?

    PDF, расм (сканер, OCR) ва эски .doc .xls .ppt файлларни Telegram ботга юборинг ёки Windows дастурида очинг — бутун папкани ҳам ўгиради.

    🔒 Файл браузерингизнинг ўзида ўгирилади. У ҳеч қаерга юкланмайди ва сақланмайди.

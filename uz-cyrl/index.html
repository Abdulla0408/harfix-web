Янги ўзбек алифбосида қайси ҳарфлар ўзгарди?

Лотин алифбосидаги тўртта ҳарф ўзгарди: oʻ → ö, gʻ → ğ, sh → ş, ch → ç. Қолган ҳарфлар аввалгидек қолади. Бу ўзгаришлар O‘RQ-1184-сон Қонун (21.10.2026) билан белгиланган.

Ҳа. Сайт, Telegram бот, Android илова ва Windows дастури бепул.

Матним ёки файлим бирор жойга юбориладими?

Йўқ. Сайтда матн ҳам, Word/Excel/PowerPoint файллар ҳам браузерингизнинг ўзида ўгирилади ва серверга юборилмайди.

Кирилл матнни ҳам ўгирадими?

Ҳа. Кирилл матнни янги лотинга ёки эски лотинга, лотин матнни эса кириллга ўгиради. Матн қайси ёзувда эканини ўзи аниқлайди.

Телефонда янги ҳарфларни қандай ёзаман?

Harfix Android иловасини ўрнатинг: унинг клавиатурасида sh, ch, oʻ, gʻ ёзсангиз, дарҳол ş, ç, ö, ğ га алмашади. Gboard каби оддий клавиатурада ҳам ишлайдиган режими бор.

Компютерда-чи?

Windows дастури исталган дастурда — Word, браузер, Telegram — ёзаётганингизда ўгиради. Матнни белгилаб Ctrl+Shift+Ҳ боссангиз, ўша жойнинг ўзида ўгирилади.

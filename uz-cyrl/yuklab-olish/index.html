Harfix'ни юклаб олиш

Янги алифбода ёзиш учун телефон ва компютерга Harfix'ни ўрнатинг. Бепул, интернетсиз ишлайди.

Android

Android 8.0 ва ундан янги · версия {андроид_версион} · {андроид_сизе}

  • Harfix клавиатураси: sh → ş, ch → ç, oʻ → ö ёзаётганда ўзи алмашади; ўзгариш керак бўлмаса — дарҳол Backspace.
  • Одатий клавиатурада: Gboard ёки бошқа клавиатура билан ёзсангиз ҳам сўз тугаши билан ўгиради.
  • Белгиланган матн: исталган иловада матнни белгилаб, менюдан «Harfix» — ўша жойда ўгирилади.
  • Файллар: Word, Excel, PowerPoint — «Улашиш → Harfix».
⬇ Android учун юклаб олиш (.apk)
Қандай ўрнатилади?
  1. Файлни юклаб олинг ва очинг.
  2. Телефон «номаълум манбадан ўрнатиш»га рухсат сўраса — Созламалар → Рухсат бериш.
  3. Ўрнатишни босинг, кейин Harfix'ни очиб, «Клавиатура» бўлимидаги қадамларни бажаринг.

«Одатий клавиатурада» режими кулранг бўлса: Созламалар → Иловалар → Harfix → ⋮ → «Чекланган созламаларга рухсат бериш».

💻

Windows

Windows 10 ва 11 (64-бит) · версия {виндовс_версион} · {виндовс_сизе}

  • Ёзаётганда ўгириш: Word, браузер, Telegram — исталган дастурда. Ctrl+Shift+Y — ёқиш/ўчириш.
  • Белгиланган матн: Ctrl+Shift+H — ўша жойнинг ўзида ўгирилади.
  • Файл ва папкалар: Word, Excel, PowerPoint, PDF, сканерлар (OCR), эски .doc — бутун папкани бир йўла.
⬇ Windows учун юклаб олиш (.exe)
Қандай ўрнатилади?
  1. Юклаб олинган Harfix-Setup.exe ни ишга туширинг. Администратор ҳуқуқи керак эмас.
  2. Windows «Windows protected your PC» деб огоҳлантирса — More info → Run anyway. Дастур ҳали рақамли имзога эга эмас, шунинг учун шундай чиқади.
  3. Ўрнатилгач, Harfix соат ёнида ишлайди ва компютер ёнганда ўзи ишга тушади.
